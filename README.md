# Data Structures and Algorithms (C++)

## 📌 Overview
This repository contains a comprehensive collection of fundamental Data Structures and Algorithms implemented in C++. These scripts were originally developed as rigorous practice for my academic midterm examinations, focusing on memory management, pointer manipulation, and algorithmic efficiency. 

The goal of this repository is to demonstrate a strong foundational understanding of core computer science concepts through raw, from-scratch implementations rather than relying on standard library templates.

## 🗂️ Repository Structure

### 1. Sorting Algorithms
Standard algorithms for organizing data arrays, focusing on understanding time and space complexities.
* `Bubble_sort.cpp`
* `Insertion_Sort.cpp`
* `Selection-Sort.cpp`
* `Merge.cpp` (Merge Sort)

### 2. Linked Lists
Dynamic data structures focusing on node manipulation and pointer arithmetic.
* `Single_linklist.cpp`
* `Double_linklist.cpp`
* `Circular_linklist.cpp`
* `List_Struct.cpp`

### 3. Stacks
LIFO (Last-In-First-Out) data structures with multiple implementation methods.
* `Stack_array.cpp` (Static implementation)
* `Stack_linklist.cpp` (Dynamic implementation)

### 4. Queues
FIFO (First-In-First-Out) data structures, including advanced variations.
* `Queue.cpp` (Standard Array/List Queue)
* `Q_Linklist.cpp` (Dynamic Queue)
* `Q-Double.cpp` (Double-ended Queue / Deque)
* `Priority-QUe.cpp` (Array-based Priority Queue)
* `Priority-QUe-LL.cpp` (Linked List-based Priority Queue)

## 🛠️ Tech Stack
* **Language:** C++
* **Concepts:** Object-Oriented Programming (OOP), Dynamic Memory Allocation, Asymptotic Analysis.
