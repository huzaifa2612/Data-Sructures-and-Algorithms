# Singly Linked List

## Description
This folder contains a C++ implementation of a Singly Linked List from scratch. It includes a comprehensive menu-driven program to test various node manipulation operations.

## Time Complexities
* **Access/Search:** $O(n)$
* **Insert at Head:** $O(1)$
* **Insert at Tail:** $O(1)$ (using a Tail pointer)
* **Insert/Delete at specific position:** $O(n)$

## Space Complexity
* $O(n)$ for storing the nodes in dynamic memory.
